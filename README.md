# صلاتي — Salat Reminder

تطبيق PWA عربي للصلاة والأحاديث، بتصميم منبّه كامل الشاشة، مواقيت الصلاة، إشعارات Web Push، واتجاه القبلة.

## المميزات
- الصلوات الخمس فقط: الفجر، الظهر، العصر، المغرب، العشاء.
- شاشة منبّه كاملة شبيهة بتجربة تطبيق المنبه: وقت كبير + اسم الصلاة + غفوة + إيقاف.
- مواقيت الصلاة حسب الموقع باستخدام طريقة الهيئة المصرية العامة للمساحة (Aladhan method 5).
- Web Push عند دخول وقت الصلاة حتى لو التطبيق ليس في الواجهة، حسب دعم النظام والمتصفح.
- الضغط على إشعار الصلاة يفتح شاشة المنبّه Full Screen ويحاول تشغيل الأذان فورًا.
- إذا منع iOS/المتصفح التشغيل التلقائي للصوت، يظهر زر كبير **تشغيل الأذان** داخل شاشة المنبّه ويعمل بلمسة واحدة.
- قبلة بالبوصلة وحساس اتجاه الهاتف.
- PWA قابل للإضافة إلى الشاشة الرئيسية على iPhone/Android.
- إعداد تشغيل/إيقاف التنبيه لكل صلاة.
- عرض جميع المواقيت وساعة المنبّه بنظام ١٢ ساعة مع ص/م، مع بقاء حسابات التنبيهات الداخلية بنظام ٢٤ ساعة.
- اختيار صوت الأذان: مشاري راشد العفاسي، الشيخ محمد رفعت، أحمد النفيس، منصور الزهراني، أو التسجيل الأصلي؛ مع معاينة وإيقاف الصوت والتحكم في مستواه وحفظ الاختيار محليًا.
- قسم «للطفل» بجوار القبلة: ٤ دروس في الوضوء وصلاة الفجر من ركعتين وأركان الإسلام والأخلاق، برسومات SVG متحركة، وانتقالات بين أوضاع الصلاة، وتحكم يدوي أو عرض متتابع كل ٨ ثوانٍ.
- ٨ أسئلة تعليمية مع تغذية راجعة تشجيعية، وحفظ نجوم التعلّم على الجهاز دون حساب. كل درس أو إجابة صحيحة يمنح نجمة مرة واحدة؛ حدّ أقصى ١٢ نجمة.
- إيقاف الحركة يدويًا واحترام إعداد تقليل الحركة في الجهاز، وإيقاف العرض المتتابع عند ترك القسم أو إخفاء التطبيق أو ظهور المنبّه.
- تبويب للأحاديث يضم ٨ أحاديث مختارة من صحيحي البخاري ومسلم، مع الراوي ورقم الحديث ورابط مصدره على Sunnah.com.
- بحث في نص الحديث والراوي والمصدر، وتصفية حسب الموضوع، مع دعم البحث العربي بدون تشكيل.
- حديث اليوم في الرئيسية يتغير حسب التاريخ المحلي، والأحاديث متاحة بدون إنترنت بعد اكتمال التخزين في أول زيارة؛ فتح روابط المصادر يحتاج إلى الإنترنت.
- **المظهر**: نهاري بألوان قسم الطفل (بنفسجي فاتح ونعناعي وكريمي)، ليلي كحلي، أو تلقائي يصبح ليليًا من المغرب حتى الفجر حسب مواقيت موقعك (أو حسب إعداد الجهاز إن لم يُحدَّد الموقع). زر سريع في الأعلى واختيار من الإعدادات.
- **تذكير قبل الصلاة** بـ ٥/١٠/١٥/٢٠/٣٠ دقيقة بإشعار خفيف، ثم المنبّه عند دخول الوقت.
- **صلّيت؟**: زر ✓ بجوار كل صلاة دخل وقتها، مع متابعة آخر ٧ أيام وسلسلة الأيام المتتالية بالصلوات الخمس (محفوظة على الجهاز لمدة ٦٠ يومًا).
- **أذكار بعد الصلاة** بعدّاد لكل ذكر ومصدر لكل منها على Sunnah.com؛ تُفتح تلقائيًا بعد تسجيل الصلاة (يمكن إيقاف ذلك).
- الغفوة ٥ دقائق تُرسل كإشعار من السيرفر حتى لو كانت الشاشة مقفولة، وإشعار الصلاة يُرسل حتى ١٠ دقائق بعد دخول الوقت لو أُعيد تشغيل السيرفر في نفس الدقيقة.
- **يعمل بدون إنترنت**: مواقيت هذا الشهر والشهر القادم تُحفظ على الجهاز، وصوت الأذان المختار يُحفظ على الجهاز فيعمل المنبّه داخل التطبيق والأذان بدون إنترنت. شارة «بدون إنترنت» تظهر أعلى الشاشة. (إشعار Web Push نفسه يحتاج إلى إنترنت لأنه يصل من السيرفر.)
- **تحديد الموقع وتفعيل التنبيهات** في الإعدادات مع حالة كل منهما، وتظهر في الرئيسية بطاقة تنبيه فقط إذا كان أحدهما غير مفعّل.
- **حركة وانتقالات**: انتقال جانبي بين الشاشات حسب اتجاه الشريط السفلي، ظهور متتابع للبطاقات، مؤشر منزلق في الشريط السفلي، تأثير ضغط على الأزرار، وتلاشي ناعم عند تغيير المظهر. كلها تتوقف تلقائيًا مع إعداد «تقليل الحركة» في الجهاز.

## إضافة أحاديث
الأحاديث محفوظة في `public/hadith.js`. أضف النص والراوي والموضوع واسم الكتاب ورقم الحديث ورابط المصدر بعد التحقق منها. عند إضافة موضوع جديد حدّث قائمة المواضيع في `public/index.html`، وعند تحديث الأحاديث غيّر إصدار التخزين في `public/sw.js` لتحديث النسخة المتاحة بدون إنترنت.

## تشغيل محلي
```bash
npm install
npm run generate-vapid
```
انسخ القيم الناتجة إلى ملف `.env` أو إلى متغيرات البيئة، ثم:
```bash
VAPID_PUBLIC_KEY=... VAPID_PRIVATE_KEY=... VAPID_SUBJECT=mailto:you@example.com npm start
```
ثم افتح `http://localhost:3000`.

## الرفع على GitHub
1. ارفع كل ملفات المشروع إلى Repository جديد.
2. لا ترفع ملف `.env`.

## الرفع على Railway
1. New Project → Deploy from GitHub Repo.
2. Railway سيكتشف Node.js ويشغّل `npm start` تلقائيًا.
3. أضف Variables:
   - `VAPID_PUBLIC_KEY`
   - `VAPID_PRIVATE_KEY`
   - `VAPID_SUBJECT=mailto:your@email.com`
   - `DATA_PATH=/data/subscriptions.json`
4. أضف Railway Volume واربطه على `/data` حتى لا تضيع اشتراكات Push بعد إعادة التشغيل.
5. Generate Domain ثم افتح الرابط من HTTPS.

## مهم على iPhone
- أضف الموقع إلى Home Screen.
- افتح التطبيق من الأيقونة المثبتة.
- اضغط “تحديد الموقع”.
- اضغط “فعّل تنبيهات الصلاة” واسمح بالإشعارات.
- iOS يتحكم في صوت إشعار Web Push في الخلفية. عند الضغط على الإشعار يفتح التطبيق على شاشة الصلاة ويحاول تشغيل الأذان مباشرة؛ وإذا منع النظام Autoplay يظهر زر تشغيل الأذان.

## صوت الأذان
أسماء التسجيلات وروابطها مستمدة من [صفحة تحميل الأذان لدى AlAdhan](https://aladhan.com/download-adhans)، والتسجيل الأصلي من Wikimedia Commons: `Muslim calling to prayer.ogg`. ملفات الصوت تُشغَّل من مصادرها، ولا تُنسخ إلى المشروع. اختيارات الأصوات محفوظة في `public/utils.js`. يلزم الإنترنت لتشغيل التسجيلات؛ مستوى الصوت المختار يطبّق على المعاينة والأذان داخل التطبيق، ولا يتحكم في صوت إشعار النظام بالخلفية.

## محتوى الطفل
الدروس والرسومات والأسئلة في `public/kids.js` وتصميمها في `public/kids.css`. الدروس مبسّطة للتعلّم مع أحد الوالدين، وتتضمن رابط مصدر للوالدين. مثال الصلاة يوضّح ركعتي الفجر والتشهد والتسليم، ولا يختصر الصلاة في ركعة واحدة. مصادر المراجعة:
- [الوضوء — صحيح البخاري ١٥٩](https://sunnah.com/bukhari:159)، و[مسح الرأس — البخاري ١٨٥](https://sunnah.com/bukhari:185).
- [الصلاة والطمأنينة — صحيح مسلم ٣٩٧](https://sunnah.com/muslim:397a)، و[التشهد — مسلم ٤٠٢](https://sunnah.com/muslim:402a).
- [أركان الإسلام — صحيح البخاري ٨](https://sunnah.com/bukhari:8)، و[المعروف — صحيح مسلم ٢٦٢٦](https://sunnah.com/muslim:2626).

## التحقق
شغّل `npm install` ثم `npm test` لاختبار المظهر التلقائي، وتسجيل الصلوات والسلسلة، ونافذة التذكير قبل الصلاة، و عرض الوقت عند منتصف الليل والظهر والمساء، والمدخلات غير الصالحة، والتأكد أن تحويل العرض لا يغيّر قيمة الوقت الأصلية المستخدمة في التنبيهات. اختبر الواجهة على الموبايل، ومعاينة الصوت والإيقاف، وتقدّم الطفل بعد إعادة الفتح.

## API مستخدم
المشروع يطلب مواقيت الصلاة من Aladhan API من السيرفر، ويخزنها مؤقتًا لتقليل الطلبات.
